# Hexapod Custom PCB

Custom PCB designed in KiCad for the Hexapod robot.

## Design Files

- `hexapod_pcb.kicad_pro` - KiCad project file
- `hexapod_pcb.kicad_sch` - Circuit schematic
- `hexapod_pcb.kicad_pcb` - PCB layout
- `hexapod_pcb.rules` - PCB design rules

## PCB Design

The PCB was designed using KiCad and is used as the custom hardware platform for the Hexapod robot.

## PCB Views

The repository root contains rendered PCB images showing the board.
